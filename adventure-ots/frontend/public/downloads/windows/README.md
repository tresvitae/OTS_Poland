# Windows client package location

Place the downloadable Windows client archive in the website workspace folder with this exact filename:

- `adventure-ots-client-windows.zip`

Final path:

- `adventure-ots/frontend/public/downloads/windows/adventure-ots-client-windows.zip`

Build and packaging script target:

- `scripts/build-otclient-x86.ps1`

The download page links to `/downloads/windows/adventure-ots-client-windows.zip`.
